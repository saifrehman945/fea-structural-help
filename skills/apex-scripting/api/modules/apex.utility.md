## Module functions

### `apex.utility.createProximitySearch() -> apex.utility.ProximitySearch`
This method creates an instance of a ProximitySearch class. ProximitySearch objects provide high performance methods to find an object within a collection of candidate objects that are physically closest to a point in space or to another object The method returns a ProximitySearch object.
