## Module Boundary Point Connections (MDCONCT) (node 3100)

Reference page: https://nexus.hexagon.com/documentationcenter/en-US/bundle/msc_apex_help/page/node/3100.html

**Keyboard shortcuts**

| Key | Action |
|---|---|
| `ESC` | Abort operation midway |
| `P` | Toggle visibility picking versus occluded picking |
| `SHIFT+MMB` | Transitions to previous selection stage |

**Module Boundary Point Connections - Manual mode**

1. Select a creation type.
2. Select a connection type from the combo box.
3. Specify the location tolerance.
4. Specify the location or a grid.
5. Click on the reference table cell to select an grid as the reference gird.
6. Click the apply button to complete.

Tips:

- Once you select a creation type, the UI will update to suit your chosen method.
- User can click the "+" button above the table to add more cells.
