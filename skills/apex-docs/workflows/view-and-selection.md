## 2D Element Properties (node 2900)

Reference page: https://nexus.hexagon.com/documentationcenter/en-US/bundle/msc_apex_help/page/node/2900.html

**Keyboard shortcuts**

| Key | Action |
|---|---|
| `CTRL` | Toggle multi select |
| `SHIFT` | Pure accumulation |
| `CTRL+SHIFT` | Pure deselection |
| `H` | Hide preselected faces |
| `SHIFT+H` | Display previous hidden faces |
| `ESC` | Abort operation midway |
| `P` | Toggle visibility picking versus occluded |

**Assign 2D Element Properties - Auto**

1. Select the entities to assign the selected 2D Element Properties to.
2. Select the entity to align the 2D Element Properties orientation.

**Assign 2D Element Properties - Manual**

1. Select the entities to assign the 2D Element Properties to.
2. Click middle mouse button (MMB).
3. Select the entity to align the 2D Element Properties orientation.
4. Click middle mouse button (MMB) or Apply button when you are ready.

**Assign 2D Element Properties - Auto**

1. Select the entities to assign the selected 2D Element Properties to.

**Assign 2D Element Properties - Manual**

1. Select the entities to assign the 2D Element Properties to.
2. Click middle mouse button (MMB) or Apply button when you are ready.

**Assign 2D Element Properties**

1. Select the Field to assign the 2D element property to, and click Apply button

## Image Capture (node 2506)

Reference page: https://nexus.hexagon.com/documentationcenter/en-US/bundle/msc_apex_help/page/node/2506.html

**Image Capture - Automatic mode**

1. Set the Following Capture Options Before Starting the Capture
2. Click the Camera (Image Capture) Button to automatically save the image using the defined tool property settings: name, location, and file type OR to copy to the Clipboard.

**Image Capture - Manual mode**

1. Click the Camera (Image Capture) Button to display the Image Capture Properties panel, and then to save the image to the defined location using the defined name OR to capture to image to the Clipboard.
2. Set the Following Capture Options
3. Click Save to save the image file with the options specified.

Tips:

- Select Current View to capture only the content of the current active view
- Select Current View Collection to capture all views in the View Collection containing the current active view
- Select Copy to Clipboard to copy the Current View or Current View Collection to the Clipboard to Paste into other applications
- Define the File Name for the saved image
- Define the Save Location for the saved image
- Define the Image File Type for the saved image

**Assign 2D Anisotropic Materials - Auto**

**Assign Anisotropic Materials - Auto**

2. Select the entity to align the material orientation.

**Assign Anisotropic Materials - Manual**

1. Select the entities to assign the anisotropic material to.
2. Click middle mouse button (MMB) or Apply button when you are ready.
3. Select the entity to align the material orientation.
4. Click middle mouse button (MMB) or Apply button when you are ready.

**Assign 3D Anisotropic Materials - Auto**

1. Select the entities to assign the selected material to.
2. Select the entity to align the material orientation.

Tips:

- To assign the same attribute to several entities, simply select those entities. Window picking helps to select many items in one shot.
- To change your attribute simply select the new attribute then select the entity
- To delete an assigned attribute, double click on the Part to get the object properties and delete the attribute of choice from the list.
- 3D Orthotropic is not supported for symmetry design space, the Analysis Readiness will block the simulation if apply this type of material to a design space with symmetry constraint.
- The default build direction is aligning with X axis of material coordinate system.
- 3D Transversal Orthotropic is not supported for symmetry design space, the Analysis Readiness will block the simulation if apply this type of material to a design space with symmetry constraint.
