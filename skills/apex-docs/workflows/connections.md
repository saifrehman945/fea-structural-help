## 3D Bolt (node 2987)

Reference page: https://nexus.hexagon.com/documentationcenter/en-US/bundle/msc_apex_help/page/node/2987.html

**Keyboard shortcuts**

| Key | Action |
|---|---|
| `H` | Hide preselected faces |
| `SHIFT+H` | Display previous hidden faces |
| `ESC` | Abort operation midway |
| `P` | Toggle visibility picking versus occluded picking |

**Auto Cross Section - Auto mode**

1. Select body(s) or body group(s) to define Bolt(s).

**Auto Cross Section - Manual mode**

1. Select body(s) or body group(s) to define Bolt(s).
2. Click MMB or Apply.

**Manual Cross Section - Manual mode**

1. Select cross section by elements/group or face(s) of the bolt, then click MMB.
2. Select the cross section by nodes/group of the bolt, then click MMB.
3. Clicks MMB to complete with default bolt axis direction or select entity(s) to define bolt axis orientation vector (1 or 2 points), then click MMB to complete.

**Auto Cross Section - Auto mode**

1. Select a body or a body group to define the Bolt.
2. Select the control node location of the Bolt.

**Auto Cross Section - Manual mode**

1. Select a body or a body group to define the Bolt.
2. Click MMB.
3. Select the control node location of the Bolt.
4. Click MMB or Apply to complete.

**Manual Cross Section - Manual mode**

1. Select cross section by elements/group or face(s) of the bolt, then click MMB.
2. Select the cross section by nodes/group of the bolt, then click MMB.
3. Clicks MMB to use default bolt axis direction or select entity(s) to define bolt axis orientation vector (1 or 2 points), then click MMB.
4. Select the control node location of the Bolt, then click MMB or Apply to complete.

Tips:

- The control node of bolt used to apply the preload is automatically generated by the system.
- In Automatic cross section method, the bolt axis orientation and cross section is automatically decided by the system.
- To select a group, you need to select it from Model browser. The valid group should contain a single solid body or mesh body only.
- If Selection multiple bodies, the system will create multiple bolts per bodies.
- If picks cross section face(s) in stage 1, selecting cross section nodes stage is not required. The system will automatically identify the cross section elements and nodes based on the cross section face and bolt axis direction.
- If you want to select the cross section face, manually partitions the bolt before the bolt definition.
- To select a group, you need to select it from Model browser. In stage1, the valid group should be a collection of 3D elements or cross section faces; in stage2, the valid group should be a collection of 3D nodes of cross section elements.

## Interaction (node 1108)

Reference page: https://nexus.hexagon.com/documentationcenter/en-US/bundle/msc_apex_help/page/node/1108.html

**Keyboard shortcuts**

| Key | Action |
|---|---|
| `H` | Hide preselected faces |
| `SHIFT + H` | Display previous hidden faces |
| `ESC` | Abort operation midway |
| `P` | Toggle visibility picking versus occluded picking |

**Auto define pairs Method - Manual mode**

1. Make sure you have assigned sections to the parts, geometry bodies or mesh bodies you want to tie.
2. Select at least 2 parts, geometry bodies or mesh bodies.
3. Click MMB.

**Auto define pairs Method - Auto mode**

1. Make sure you have assigned sections to the parts, geometry bodies or mesh bodies you want to tie.
2. Select at least 2 parts, geometry bodies or mesh bodies to tie (to multi select, use window selection, or hold down CTRL or SHIFT, then select, then release the keys).

**Procedure**

1. To see what additional entities are connected to the displayed entities just click the Grow button

**Manual define pairs Method - Auto mode**

1. Select entities for the first side of Interaction
2. Select entities for the second side of Interaction

**Manual define pairs Method - Manual mode**

1. Select entities for the first side of Interaction
2. Click MMB
3. Select entities for the second side of Interaction
4. Click MMB or apply

**Manual define pairs Method - Auto mode**

1. Select entities for the Self-Contact

**Manual define pairs Method - Manual mode**

1. Select entities for the Self-Contact
2. Click MMB

**Deform Body - Auto mode**

1. Select entity(s) or property(s) to define deform body

**Deform Body - Manual mode**

1. Select entity(s) or property(s) to define deform body
2. Click MMB or Apply to complete

Tips:

- For 2D geometry and meshes, make sure you have assigned sections to the entities you wish to tie.
- The Pair tolerance is used to determine which bodies will be tied. Bodies that are separated by less than this distance tolerance value will be tied. For 2D geometry or meshes, the section thickness and offset will be accounted for in the proximity calculation.
- The Contact tolerance is used to determine which element faces will be included in the patch. The Pair bodies must contain meshes for patches to be created. When the 'Auto' option is chosen, the system will determine the patch tolerance automatically based on the mesh size and the separation of the bodies. For 2D meshes, section thickness and offset will be used in determining the elements.
- To show which entities connect to a set of items, it is recommended that you isolate (show only) the set of items and then proceed to grow.
- Another good way to visualize the glue list is to just turn on the interaction manager before proceeding to click the grow button.
- You can select body or a collection of faces/elements or contact body(s) to define pair. To select the contact body, you need to select it in model browser
- To select multiple entities at the same time, hold down the SHIFT or the CTRL key, then select the entities you want. Alternatively, you can use box picking as well
- You can select body(s) or a collection of faces/elements, nodes or element property(s) to define deform body. To select the element property, you need to select it in model browser
- You can turn on the "Display 2D element layer" button to check the 2D element layer. The top side will be rendered ad cyan color and the bottom side will be rendered as brown color
